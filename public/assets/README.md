# Assets

This directory contains all game assets for ERGo!

## Structure

- **images/** - Static images (backgrounds, UI elements, etc.)
- **sprites/** - Sprite sheets and animated sprites (insects, effects, etc.)

## Image Guidelines

- Use PNG format for images with transparency
- Use JPEG for backgrounds without transparency
- Keep individual images under 1MB when possible

## Sprite Guidelines

- Use sprite sheets for animated characters
- Standard frame size: 32x32 or 64x64 pixels
- Format: PNG with transparency
