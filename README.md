## 🎯 About

Explore images through the unique visual systems of different insects. Each species has scientifically accurate spectral sensitivities based on real photoreceptor research.

## 🐛 Insect Families

- 🐝 **Hymenoptera** - Bees, wasps, ants
- 🪰 **Diptera** - Flies, mosquitoes
- 🦋 **Lepidoptera** - Butterflies, moths
- 🪲 **Coleoptera** - Beetles
